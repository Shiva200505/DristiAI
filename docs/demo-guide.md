# Demo guide

Run `python scripts/demo_prep.py`, start both services, and open the browser UI. Edit or select `workspace/services/auth.py`, run the scan, open the SQL finding, review the evidence and candidate diff, apply only after approval, then verify. Use the Performance and Privacy views to show `DEV_MACHINE`, `TEMPLATE_FALLBACK`, and local-only state. The eight fixtures in `demo-repo/` provide repeatable detector coverage.
